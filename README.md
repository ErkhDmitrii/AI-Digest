# 🤖 AI-Дайджест Грузия

**AI-Дайджест** — это умный микросервис на Python, который автоматически собирает деловые новости Грузии, фильтрует их с помощью искусственного интеллекта, формирует структурированный дайджест и отправляет его на модерацию администратору для последующей публикации в Telegram-канал.

Проект решает проблему информационного шума: вместо десятков постов из разных источников вы получаете один сжатый выпуск, разделенный по категориям, с акцентом на **влияние на бизнес**.

## ✨ Ключевые возможности

*   **Мультиисточниковый сбор:** Парсинг Telegram-каналов (через `Telethon`) и веб-сайтов (через `BeautifulSoup` + `curl_cffi`).
*   **Обход защит:** Использование `curl_cffi` для имитации отпечатков реального браузера (обход Cloudflare и 403 Forbidden).
*   **Умная фильтрация:** LLM оценивает релевантность новости для предпринимателей и распределяет по категориям (`Законы и налоги`, `Банки и платежи`, `Рынок и инфраструктура`).
*   **AI-саммаризация:** Генерация краткой сути новости и выделение блока «Влияние на бизнес» с помощью моделей DeepSeek / OpenAI.
*   **Защита от дублей:** Использование алгоритма `SimHash` для отсеивания повторяющихся новостей из разных источников.
*   **Ручная модерация:** Бот присылает готовый черновик администратору с inline-кнопками «Опубликовать», «Редактировать», «Отклонить».
*   **Устойчивость:** Корректная обработка сетевых таймаутов, автоматическое закрытие сессий `aiohttp` и защита базы данных от блокировок.

## 🧠 Архитектура и пайплайн

Процесс работает автономно по расписанию (через `APScheduler`):

1.  **Сбор (Collect):** Бот опрашивает источники из `sources.yaml`.
2.  **Дедупликация:** Новые статьи проверяются по базе (SQLite) на уникальность.
3.  **Фильтрация (Filter):** LLM-классификатор (Промпт 1 и 2) отсеивает нерелевантный новостной мусор.
4.  **Саммаризация (Summarize):** LLM-редактор (Промпт 3) сжимает статьи в короткие блоки.
5.  **Постпроцессинг:** Очистка от артефактов LLM, нормализация Markdown, обрезка до лимитов Telegram.
6.  **Модерация:** Черновик отправляется администратору в Telegram.
7.  **Публикация:** По нажатию кнопки контент уходит в целевой канал.

## 🛠 Технологический стек

*   **Язык:** Python 3.10+
*   **Бот:** `aiogram 3.x` (Асинхронный Telegram Bot API)
*   **Сбор из TG:** `Telethon`
*   **Веб-парсинг:** `BeautifulSoup4`, `lxml`, `curl_cffi`
*   **ИИ:** `openai` (совместим с DeepSeek API)
*   **База данных:** `aiosqlite` (SQLite)
*   **Планировщик:** `APScheduler`

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/ваш-username/ai-digest.git
cd ai-digest
```

### 2. Создание виртуального окружения
**Windows:**
```bash
python -m venv venv
.\venv\Scripts\activate
```
**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации
Создайте файл `.env` в корне проекта и заполните его:

```env
# === Telegram Bot ===
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_CHAT_ID=ваш_личный_id_от_userinfobot
TARGET_CHANNEL_ID=-100xxxxxxxxxx  # ID канала (бот должен быть админом)

# === Telethon (Userbot для чтения каналов) ===
TELETHON_API_ID=ваш_api_id
TELETHON_API_HASH=ваш_api_hash

# === LLM (DeepSeek / OpenAI) ===
LLM_API_KEY=ваш_api_ключ
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# === Настройки расписания ===
COLLECT_INTERVAL_MINUTES=5
DIGEST_HOUR=8
```

### 5. Настройка источников
Отредактируйте файл `sources.yaml`, чтобы указать нужные RSS-ленты, Telegram-каналы и веб-сайты для парсинга.

### 6. Запуск бота
```bash
python main.py
```

## 🌍 Деплой на сервер (Production)

Для работы 24/7 рекомендуется развернуть проект на VPS (Ubuntu 22.04+).

1. Установите зависимости и настройте `.env`.
2. Создайте systemd-сервис `/etc/systemd/system/aidigest.service`:

```ini
[Unit]
Description=AI Digest Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/ai-digest
ExecStart=/path/to/ai-digest/venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

3. Запустите сервис:
```bash
sudo systemctl daemon-reload
sudo systemctl enable aidigest
sudo systemctl start aidigest
```
