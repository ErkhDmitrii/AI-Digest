# 🤖 AI-Дайджест Грузия (Solidus)

**AI-Дайджест** — это умный микросервис на Python, который автоматически собирает деловые новости Грузии, фильтрует их с помощью искусственного интеллекта, формирует структурированный дайджест и отправляет его на модерацию администратору для последующей публикации в Telegram-канал бизнес-клуба Solidus.

Проект решает проблему информационного шума: вместо десятков постов из разных источников вы получаете один сжатый выпуск, разделенный по категориям, с акцентом на факты и цифры.

## ✨ Ключевые возможности

*   **Мультиисточниковый сбор:** Парсинг Telegram-каналов (через `Telethon`) и веб-сайтов (через `BeautifulSoup` + `curl_cffi`).
*   **Обход защит:** Использование `curl_cffi` для имитации отпечатков реального браузера (обход Cloudflare и 403 Forbidden).
*   **Умная фильтрация:** LLM оценивает релевантность новости для предпринимателей и распределяет по категориям (`Законы и налоги`, `Банки и платежи`, `Рынок и инфраструктура`).
*   **Отсев рекламы:** Жесткие правила в промптах исключают попадание рекламы, партнерских постов и промокодов в финальный дайджест.
*   **AI-саммаризация:** Генерация краткой сути новости с помощью моделей DeepSeek / OpenAI (без лишних вводных фраз).
*   **Защита от дублей:** Использование алгоритма `SimHash` для отсеивания повторяющихся новостей из разных источников.
*   **Ручная модерация:** Бот присылает готовый черновик администратору с inline-кнопками  «Опубликовать», «Редактировать», «Отклонить». Если новостей нет — присылает уведомление без кнопок.
*   **Устойчивость:** Корректная обработка сетевых таймаутов, автоматическое закрытие сессий `aiohttp` и защита базы данных от блокировок.

## 🧠 Архитектура и пайплайн

Процесс работает автономно по расписанию (через `APScheduler`):

1.  **Сбор (Collect):** Бот опрашивает источники из `sources.yaml` (каждые N минут).
2.  **Дедупликация:** Новые статьи проверяются по базе (PostgreSQL) на уникальность.
3.  **Фильтрация (Filter):** LLM-классификатор (Промпт 2) отсеивает нерелевантный мусор и рекламу.
4.  **Саммаризация (Summarize):** LLM-редактор (Промпт 3) сжимает статьи в короткие блоки.
5.  **Постпроцессинг:** Очистка от артефактов LLM, нормализация Markdown, обрезка до лимитов Telegram.
6.  **Сборка:** Формируется шапка с датой и подпись канала Solidus.
7.  **Модерация:** Черновик отправляется администратору в Telegram.
8.  **Публикация:** По нажатию кнопки контент уходит в целевой канал.

## 🛠 Технологический стек

*   **Язык:** Python 3.10+
*   **Бот:** `aiogram 3.x` (Асинхронный Telegram Bot API)
*   **Сбор из TG:** `Telethon`
*   **Веб-парсинг:** `BeautifulSoup4`, `lxml`, `curl_cffi`
*   **ИИ:** `openai` (совместим с DeepSeek API)
*   **База данных:** `asyncpg` (PostgreSQL)
*   **Планировщик:** `APScheduler`
*   **Контейнеризация:** Docker, Docker Compose

## 🚀 Установка и запуск (через Docker)

Для работы проекта на компьютере или сервере должен быть установлен **Docker** и **Docker Compose**.

### 1. Клонирование репозитория
```bash
git clone https://github.com/ErkhDmitrii/AI-Digest.git
cd AI-Digest
```

### 2. Настройка конфигурации
Создайте файл `.env` в корне проекта и заполните его:

```env
# === Telegram Bot ===
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_CHAT_IDS=ваш_личный_id,id_второго_админа  # Можно указать несколько через запятую
TARGET_CHANNEL_ID=-100xxxxxxxxxx  # ID канала (бот должен быть админом)

# === Telethon (Userbot для чтения каналов) ===
TELETHON_API_ID=ваш_api_id
TELETHON_API_HASH=ваш_api_hash

# === LLM (DeepSeek / OpenAI) ===
LLM_API_KEY=ваш_api_ключ
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# === Настройки расписания ===
COLLECT_INTERVAL_MINUTES=10
DIGEST_HOUR=8
```

### 3. Настройка источников
Отредактируйте файл `config/sources.yaml`, чтобы указать нужные RSS-ленты, Telegram-каналы и веб-сайты для парсинга.

### 4. Запуск контейнеров
```bash
docker compose up -d --build
```

## 🧪 Тестирование пайплайна

Если вы хотите принудительно запустить генерацию дайджеста (не дожидаясь времени по расписанию), выполните эти команды на сервере:

```bash
# 1. Остановить фонового бота
docker compose stop ai-digest-bot

# 2. Запустить тестовый скрипт
docker compose run --rm ai-digest-bot python -c "import asyncio; from db.database import init_db; from bot.scheduler import scheduled_digest; from bot.handlers import bot; exec('async def run():\n    await init_db()\n    await scheduled_digest()\n    await bot.session.close()'); asyncio.run(run())"

# 3. Вернуть бота в фон
docker compose start ai-digest-bot
```
*Скрипт соберет свежие новости, прогонит их через ИИ и отправит черновик вам в Telegram.*

## 🌍 Деплой на сервер (Production)

Проект полностью готов к развертыванию на VPS (Ubuntu 22.04+).

1. Установите Docker и Docker Compose.
2. Склонируйте репозиторий и настройте `.env` (не забудьте загрузить файл сессии `ai_digest_session.session` для Telethon).
3. Запустите проект:
   ```bash
   docker compose up -d --build
   ```
4. Для обновления кода после внесения изменений в Git:
   ```bash
   git pull origin main
   docker compose up -d --build
   ```
